卡塞尔启动动画 · DeepSeek Harness 插件
==========================================

装上之后，每次启动 DeepSeek Harness 会先播放一段六屏「授权」动画，
点一下（或按 Enter）走下一步，最后点「接入终端」交接给主界面。


怎么装（五种方式，任选一种）
----------------------------

【方式一】一行命令（最省事，不用下载任何文件）

  打开「终端」，粘贴：

    curl -fsSL https://cdn.jsdelivr.net/gh/Ffwjl010831/dsh-plugin-kassel-boot@v0.1.1/install.sh | bash

  看到「安装完成」后，⌘Q 完全退出 DeepSeek Harness，再打开。


【方式二】双击安装

  1. 右键点「安装卡塞尔启动动画.command」→ 选「打开」
  2. 弹出「无法验证开发者」时，再点一次「打开」
  3. 看到「安装完成」后按回车关窗口
  4. 完全退出 DeepSeek Harness（⌘Q），重新打开


【方式三】终端安装（方式二被系统拦住时用这个）

  打开「终端」，粘贴以下两行（第一行最后的路径改成你实际放文件的目录）：

    cd ~/Downloads
    sh 安装卡塞尔启动动画.command

  想更省事：把文件拖进终端窗口，路径会自动填好。


【方式四】如果还给了你一个 .tgz 文件

    cd ~/Downloads
    sh install.sh dsh-kassel-boot-0.1.1.tgz


【方式五】用 dsh plugin add 安装（和 dsh-startup-screen 一样）

  前提：先打开一次 DeepSeek Harness（让它初始化 profile），然后 ⌘Q 完全退出。

  1) 下载安装包（在「终端」里跑）：

     cd ~/Downloads
     curl -fL -O https://github.com/Ffwjl010831/dsh-plugin-kassel-boot/releases/download/v0.1.1/dsh-kassel-boot-0.1.1.tgz

  2) 装进 DSH：

     dsh plugin --profile desktop add ./dsh-kassel-boot-0.1.1.tgz

  如果提示 dsh: command not found，说明命令行工具没装进 PATH，
  改用完整路径：

     "/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" plugin --profile desktop add ./dsh-kassel-boot-0.1.1.tgz

  这条会下载插件、装进 profile，并自动把 dsh-kassel-boot 写进 bundles，
  不用再手改任何配置文件。跑完重新打开 DSH 即可。

  卸载：dsh plugin --profile desktop remove dsh-kassel-boot

  不要用 dsh plugin add github:用户名/仓库 —— 这条路要求走 git 拉取，
  部分网络会直接报 502，而且还会被 pnpm 拦构建。


卸载
----

  在线装的，用这条：

    curl -fsSL https://cdn.jsdelivr.net/gh/Ffwjl010831/dsh-plugin-kassel-boot@v0.1.1/install.sh | bash -s -- --uninstall

  本地装的，用这条：

    sh 安装卡塞尔启动动画.command --uninstall

  用方式五装的，用这条：

    dsh plugin --profile desktop remove dsh-kassel-boot

  或者直接双击「卸载卡塞尔启动动画.command」。
  卸载后同样要 ⌘Q 重启。


常见问题
--------

Q: 提示「'安装卡塞尔启动动画.command' 因为来自身份不明的开发者无法打开」
A: 右键 →「打开」→ 再点「打开」。或者直接用「方式三」的终端命令。

Q: 提示 Permission denied
A: 先执行 chmod +x 安装卡塞尔启动动画.command，再运行。

Q: 装完没看到动画
A: 必须完全退出（⌘Q，不是关窗口）再重新打开。
   另外如果你之前装过 dsh-startup-screen 之类的启动插件，两个会抢同一个
   位置，去插件列表里关掉另一个。

Q: 动画能跳过吗
A: 右上角有 SKIP，直接跳到最后一屏。

Q: 每一屏都得手动点吗
A: 是。默认不自动播放，点一下或按 Enter / 空格进下一屏。

Q: 怎么看装好了没
A: 终端执行   ls ~/.dsh/plugins/dsh-kassel-boot   能看到文件就是装上了。


说明
----

· 插件装在 ~/.dsh/plugins/dsh-kassel-boot，只改 profile 的 package.json 加一行，
  其余东西不碰；卸载时会把配置那行删干净。
· 安装脚本会在 profile 目录留一份 package.json.bak-dsh-kassel-boot 备份。
· 动画内容写死在插件里，不联网、不读你的任何数据。
